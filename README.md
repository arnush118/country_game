#  Country Guessing Game

A simple command-line guessing game where you try to match the computer's randomly chosen country.

##  How It Works

The computer randomly picks a country from a list of 9 options. You enter your guess, and the game tells you whether you won or lost.

##  Available Countries

`italy` · `australia` · `usa` · `japan` · `france` · `england` · `canada` · `china` · `germany`

## Usage

```bash
python game.py
```

### Example

```
let's start the game
please enter your guess: japan
pc choice is japan
you're choice is japan
win :)
```
